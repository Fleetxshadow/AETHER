## Deliberate implementation choices

MapLibre owns clustering, heat, extrusion, popups, and geospatial navigation. Adding deck.gl for the same demonstration would duplicate that work. Native accessible controls serve the application; a second component framework was unnecessary. Web Audio generates original optional tones. SVG charts include readable summaries and data tables. Procedural Three.js geometry avoids external model downloads and dubious asset licenses. Three.js is pinned to a release compatible with the installed R3F clock API.

No live backend, LLM account, real surveyed model, actual hardware specification, verified camera evidence, or real team roster was supplied. The application labels those boundaries and provides useful local demonstrations rather than inventing them.
