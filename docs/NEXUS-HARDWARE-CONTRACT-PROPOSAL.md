# Hardware addendum proposed to AGY — 2026-10-27

Status: PROPOSED, hardware API v1 implemented for local validation; AGY adoption and website end-to-end integration pending. Shared v1.0.0 contract is preserved verbatim. This file is the shared review artifact; no direct AGY acknowledgement is claimed.

Device agent loopback :8765 → SSH tunnel → laptop gateway loopback :8766 → AGY server-side adapter → AETHER. GET only, Bearer tokens kept server-side, no CORS/browser secrets. No POST ingest or actuators. Configure source endpoints locally, never from HTTP requests.

Agent/gateway endpoints: /health, /devices, /telemetry, /camera/status, /camera/stream?id=ID, /camera/snapshot?id=ID. Gateway also offers /api/nexus/feeds as a strict AETHER subset and /api/nexus/devices, /api/nexus/telemetry, /api/nexus/cameraStatus. Agent timestamped envelope: schema_version 1.0.0, device_id, device_type, timestamp, source LIVE|STALE|OFFLINE. Measurements carry value, unit, observed_at, source and error; unavailable values are null. CPU temperature is component=cpu, not ambient. Performance/resource channels stay system metrics and are not fabricated city health/battery channels.

Source describes actual observation, not endpoint HTTP success: live host health does not imply live cameras. Offline camera with a retained frame is STALE until expired (60 s), then OFFLINE. Camera online requires a recent successful frame and a current connected state. Disconnection immediately removes online status; stale cached frames are never served as live snapshots/streams. Server measurement time is receipt time; ESP32 uptime is not UTC. /camera/stream uses multipart/x-mixed-replace, boundary=nexus-frame, per-frame Content-Length. Max 2 MiB JPEG, capped frame rate, one acquisition worker per source; multiple bounded viewers share it.

AETHER adapters: project only real device identifiers, real lastSeen, status and source into strict device schema. No host resource measurement is mapped into a city channel: telemetry is empty in the strict AETHER subset. CPU temperature remains explicitly component=cpu in the hardware telemetry endpoint. No external sensor readings are synthesized. CameraStatus remains empty in AETHER feeds because its current validator supports only mediamtx/vdo-ninja; detailed MJPEG availability is in hardware /camera/status. No fake MediaMTX/WebRTC endpoint is claimed. AGY must bridge MJPEG or extend the validator, and retain CPU component semantics if displaying temperature. AGY can add a typed CPU resource adapter without treating CPU temperature as ambient temperature.

Errors: {error, code, details, timestamp, source:OFFLINE}; HTTP 401 unauthorized, 400 invalid ID/config, 404 unknown path/source, 503 no fresh frame/upstream unavailable, 429 viewer limit, 405 unsupported mutation. Auth failures do not echo secrets. Pi unavailable yields empty AETHER feeds with source OFFLINE, not demo-labelled live data. AETHER demo fallback belongs to AGY's provider.

AGY action: replace the fixed LIVE backend records identified in the inventory. Poll authenticated loopback gateway server-side with a timeout, preserve freshness and device connectivity, and do not forward token/config/serial controls into browser payloads. Gateway is separately launchable and does not alter the running AI backend.
